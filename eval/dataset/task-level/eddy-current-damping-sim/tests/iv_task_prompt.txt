**Project Brief: Eddy‑Current Damping Simulation**

**Objective**  
Create an interactive web‑based visualizer that demonstrates eddy‑current damping. Users will slide a permanent magnet across a conductive plate, observe the induced current loops, and see the resulting drag force in real time. The tool should serve both as an educational demo and as a foundation for further physics‑based extensions.

**Key Goals**  
1. **Accurate physics** – Implement Maxwell‑Faraday induction and Lorentz‑force calculations to derive realistic eddy‑current strength and drag.  
2. **Clear visual feedback** – Show induced currents as animated swirling loops on the plate, with intensity/color tied to current magnitude.  
3. **Quantitative display** – Continuously compute and render the drag force (N) and magnet velocity (m/s).  
4. **User interaction** – Drag the magnet with mouse / touch, adjust parameters (magnet strength, plate conductivity, plate thickness, gap distance).  
5. **Responsive design** – Full‑screen and windowed modes on desktop and tablet browsers.  
6. **Extensible architecture** – Modular code (e.g., separate physics engine, rendering layer, UI) to allow future extensions (e.g., multiple magnets, rotating plates).

**Must‑Haves**  
- **Technology stack**: HTML5 Canvas 2D (or WebGL if performance demands), JavaScript/TypeScript, no external proprietary plugins.  
- **Physics engine**:  
  - Compute induced eddy currents using a discretized plate mesh.  
  - Calculate drag force \( \mathbf{F}_d = -k\,\mathbf{v} \) derived from the integrated Lorentz forces on the currents.  
  - Support variable material properties (conductivity σ, permeability μ).  
- **Visualization**:  
  - Swirling current loops drawn as curved arcs or streamlines, animated to indicate direction.  
  - Color gradient (e.g., blue → red) representing current density magnitude.  
  - Optional “field‑line” overlay for magnetic flux for completeness.  
- **UI controls**:  
  - Slider/input
