The RealCLI Leaderboard

RealCLI is a paired benchmark of real-world CLI tasks that measures both what agents can do on their own and how well they work with people. Every task is run twice — once autonomously (RealCLI-Exec) and once with a scripted user in the loop (RealCLI-Collab) — in the same containerized environment with the same verifier.

101 real CLI tasks 10 categories · 52 subdomains 51 collaboration scenario templates 1,658 checklist items 11 models × 3 scaffolds

EXEC Autonomous execution

The agent receives the full task specification up front and works alone. Scored by Rexec — pass rate against a deterministic verifier (or VLM judge for visual tasks).

COLLAB Collaboration with a scripted user

The agent starts from an incomplete request; a scripted user simulator reveals information and injects probes (clarifications, corrections, constraint changes, authorization decisions). Scored by Rcollab (pass rate), Scollab (collaboration quality across 5 dimensions), and their product Jcollab = Rcollab × Scollab.
